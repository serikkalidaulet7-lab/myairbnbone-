# Bliżej Nieba

Польский демонстрационный сайт дома в Богдановке. HTML, CSS и JavaScript без сборки и зависимостей. Готовый сайт находится в папке `public/`.

## Предпросмотр

`npm run dev` — http://127.0.0.1:4173 (требуется Python 3).

Также можно открыть `public/index.html` напрямую. `npm run check` проверяет синтаксис JavaScript.

## Публикация в Cloudflare Pages

Для этого проекта в Cloudflare Pages выберите:

- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `public`

Cloudflare загрузит только содержимое `public/`, поэтому служебные файлы и `node_modules/` не попадут в публикацию.

## Реализовано

- Адаптивный дизайн, мобильное меню, плавная прокрутка и анимация с учётом reduced motion.
- Шесть фотографий реального объекта и модальная галерея с клавиатурной навигацией.
- Дом, удобства, spa, окрестности, ссылки на отзывы и FAQ.
- Обязательные даты, проверка порядка дат, число гостей 1–5, питомец, подсчёт ночей.
- Переход к объявлению Airbnb с датами, количеством гостей и питомцем. Состав гостей по возрастам нужно уточнить на Airbnb; выбранное число передаётся как adults.
- Никаких вымышленных цен, отзывов, свободных дат или подтверждений бронирования.

## Источники и ограничения

Описание и характеристики: материал заказчика и https://www.airbnb.com/rooms/1227386357733713880 . Дата подготовки: 29.09.2026. Высота 820 м взята из полного описания, хотя заголовок округлён до 800 м. Число отзывов не закреплено в макете из-за расхождения 85/86 в доступных версиях объявления.

Фото в assets скачаны из этого объявления для демонстрационного проекта. Использование фотографий при передаче и публикации нужно согласовать с правообладателем. Оригиналы принадлежат их владельцам, существующая LICENSE репозитория не предоставляет права на эти фотографии.

Референс: https://dribbble.com/shots/27388289-Mission-responsive-landing-page . Использованы принципы крупной типографики, сетки, контраста и акцентного цвета; реализация самостоятельная.

Шрифты Manrope и DM Sans загружаются через Google Fonts; при отсутствии сети используется Arial. Все фотографии хранятся локально.

Это локальный демонстрационный сайт, не опубликованный от имени владельца. Нет прямой оплаты, личного кабинета, синхронизации календаря или отправки заявок. Доступность, конечные цены, правила и оплата — на Airbnb. Карта ведёт к окрестностям, точный адрес не придуман.
